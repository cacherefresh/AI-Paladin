# ui/
Two audiences, two dashboards, one data source (task + node + event records).

- ops/   - engineers: node status/roles, live task feed, security flags
           (blocked commands, behavioral alerts, pending package approvals)
- exec/  - leadership: who's developing, tasks completed per tier,
           tokens local vs cloud, $ saved vs all-cloud baseline,
           savings from memory reuse (claude-mem/vault hits) and skills reuse
